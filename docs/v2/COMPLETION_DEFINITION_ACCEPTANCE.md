## 设计和隐私修复

本轮移除了学生端全部 WXML 内联样式，新增语义 WXSS 类，并将两个动态宽度进度条替换为 `assessment-progress` 分段进度组件。这样满足 `AGENT.md` 禁止 HTML `style` 属性的硬约束，同时保留 `FRONTEND_GUIDELINES.md` 的颜色、间距、热区和进度表达规则。

安全静态检查仍确认：安全支持页面不显示不必要的分数、历史、AI 或身份；学生端请求只经过业务 API；审计和 AI 输入使用最小脱敏投影。
