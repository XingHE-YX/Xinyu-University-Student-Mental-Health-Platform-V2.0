# 心语 V2 每日短句库与来源记录

## 1. 文档信息

- 版本：quote-library-v1
- 建立日期：2026-08-27
- 当前状态：数据结构、审核规则和首批启用内容已确认；现代作品候选在版权/版本核验前保持禁用
- 展示格式：`短句——作者 / 作品`

短句库由项目自行维护。内容不在运行时抓取互联网，不由大模型临时生成，也不根据用户心情、自测或安全状态做个性化。每次进入今日页或主动点击“换一句”时，从已启用条目中随机获取；停留期间不自动切换。

## 2. 数据结构

每条记录至少包含：

| 字段 | 说明 |
| --- | --- |
| `quote_id` | 稳定编号，如 `Q-0001` |
| `text` | 展示短句，不含末尾出处 |
| `source_display` | 破折号后的作者/作品 |
| `category` | 古典、名言、原创、现代作品 |
| `language_version` | 原文、简体转写或明确的意译 |
| `source_url` | 公开核验链接 |
| `rights_status` | 公版、项目原创、待版权核验、禁用 |
| `review_status` | 待核验、已核验、已启用、已停用 |
| `review_note` | 语境、版本、敏感性和版权说明 |

## 3. 收录标准

启用条目必须同时满足：

- 出处和文本可以追溯；
- 不把网络流行句误标为名人原话；
- 不含诊断、治疗、危险挑战、羞耻、道德绑架或“只要努力就一定成功”的绝对承诺；
- 不暗示用户当前处于危机，不替代支持资源；
- 不根据某种心情推送对应短句；
- 现代作品使用正式中文版本或明确标记的意译，并完成权利状态核验；
- 同一来源不过度摘录，不收录歌词；
- 长度优先控制在 8–32 个汉字，过长内容只取语义完整的短句。

公版古典文本可以启用；项目原创内容可以启用；现代动漫、影视和在世作者内容默认 `待版权核验`，未通过前不进入线上随机池。

## 6. 抽取与去重规则

- 只从 `review_status=已启用` 且 `rights_status=公版/项目原创` 的记录中抽取；
- 同一会话内“换一句”不立即重复上一条；
- 短句不按情绪、分数、身份、树洞内容或安全状态加权；
- 不设置“坚持天数”“阅读奖励”或收藏排行；
- 条目停用后不影响历史截图，但线上不再抽取；
- 同一文本仅保留一个主记录，异体字和简繁转换写入版本字段，不重复计数。

## 7. 语境与安全复核

短句编辑者在启用前检查：

- 是否可能责备正在疲惫、焦虑或低落的用户；
- 是否暗示“失败只因不够努力”；
- 是否把痛苦浪漫化、把危险行为当作勇敢；
- 是否包含死亡、自伤、药物、酒精、暴力或羞辱语境；
- 是否与今日页的非个性化随机机制相容。

存在歧义时宁可停用。短句区不是安全支持入口；现实支持资源始终使用独立、可配置的产品入口。
