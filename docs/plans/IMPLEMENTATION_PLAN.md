# 心语 V2 后续实施计划

## 1. 计划范围

本计划面向已有的小程序、Python 后端和 Vue 管理后台，不再以“只有设计文档”为起点。
功能范围见 [产品需求](../product/PRD.md)，系统边界见 [系统设计](../../DESIGN.md)。
这里维护后续工作及外部依赖，不保存逐次开发日志、历史验收结果或线上服务状态。

## 2. 已有工程基础

| 模块 | 仓库内已有结构 |
| --- | --- |
| 小程序 | 登录与身份入口、今日与心情、自测与结果、树洞、我的与删除流程 |
| 后端 | 认证、同意、身份、固定规则、安全支持、树洞审核、后台任务、审计、AI 与仓储适配 |
| 后台 | 登录、统一工作台、任务详情、异常状态、审计及演示重置 |
| 发布 | CloudBase 环境模板、Python 函数打包、后台托管、小程序环境配置及本地演示 |

这些说明代码和工具已经存在，不代表当前运行环境就绪、所有路径已验证或正式上线已经获批。

## 3. 需要外部确认的事项

- 学校正式授权、真实身份核验接口、数据保存期限和隐私文本。
- PHQ-9、GAD-7 中文文本与使用授权，以及固定结果、安全文案和睡眠观察规则的专业核验。
- 真实支持资源的名称、联系方式、开放时间、维护责任，以及安全支持的角色与交接机制。
- 每日短句的版本与权利状态；未通过核验的现代作品候选保持禁用。

这些事项不能由演示数据或开发者自行补写。未获确认时维持合成身份、演示占位或未配置状态。
具体边界见 [产品决策](../product/V2_CONFIRMED_PRODUCT_DECISIONS.md) 与
[量表依据](../product/V2_ASSESSMENT_MEDICAL_EVIDENCE_AND_REFERENCES.md)。

## 4. 正式发布准备

1. 使用正式小程序账号与授权环境；演示中使用或曾暴露的凭据轮换后再按环境配置。
2. 建立与演示环境分离的 EnvID、数据库、会话秘密、函数和静态托管配置。
3. 对接已授权的学校身份接口和真实支持资源，不复用固定合成核验路径或占位联系方式。
4. 按实际配置确认 HTTPS 域名、CORS、后台深层路由回退和客户端环境选择。
5. 明确数据访问、删除、保留、备份与运行维护责任；结合真实依赖验证核心路径。

部署步骤集中在 `docs/develop/deploy/`，配置字段集中在
[环境配置](../develop/CONFIGURATION_REGISTRY.md)，本计划不重复维护部署命令。

## 5. 持续维护

- 依赖与工具链升级前处理 peer 兼容性、Vue 模板检查和源码 lint 的现有限制。
- API、数据库集合和权限调整时同步专题文档及相关测试。
- 持续保持 AI 失败回退、固定评分、安全分支、人工审核与演示隔离边界。
- 对真实资源、短句来源和外部接口明确维护责任，避免历史材料替代现行说明。

新需求确认后再补充目标、影响范围和实现顺序，不把未经确认的功能写成既定承诺。
