# 2026 答辩演示

本批次仅用于隔离的 `xinyu-v2-demo` 环境。姓名、测评和树洞正文均为虚构；
树洞匿名昵称带「演示」字样。不会创建微信登录凭据、触发真实通知或调用学校身份服务。
指定保留学号不属于本批次，导入程序不会为它创建占位或更新任何已有数据。

## 现场顺序

1. 用原体验版二维码进入小程序，打开树洞，找到匿名昵称带「演示」的内容。
2. 登录原有演示管理后台，点侧边栏「答辩数据总览」。查看 30 名合成参与者、495 份问卷、108 条树洞和按人统计的 15 / 12 / 3 筛查分布。
3. 选一个日期范围，先看复测和发帖两条时间序列，再切换到睡眠观察，展示它不纳入风险分级。展开脱敏明细查看合成案例的提交与发帖次数。

时间轴为北京时间 2026-08-27 至 2026-11-22，前 5 天为学期前导入周。
三套问卷各 165 份，每人每套 5–6 次；树洞每人 3–4 条。
风险以筛选期内最近一份 PHQ-9 与最近一份 GAD-7 的较高档计算，每人只计一次。
分时段图按筛查提交次数统计，深夜定义为 23:00–03:59。这是演示设计，不是实证规律。

## 导入与核验

在 `backend/` 运行。环境文件只放在本机，包含已登记的演示环境 ID 和所需密钥，不提交 Git：

```sh
uv run --locked python -m scripts.defense_import preview --env-file /path/to/.env.demo.local
uv run --locked python -m scripts.defense_import apply --env-file /path/to/.env.demo.local
uv run --locked python -m scripts.defense_import verify --env-file /path/to/.env.demo.local \
  --snapshot ../admin/src/defense-data.json
```

导入只接受项目登记的答辩 CloudBase 环境；写前检查学号冲突、已启用问卷版本和本批次已有文档。
相同记录不重复插入，不同记录停止执行。写后逐批读取并核对文档与保留号。
后台使用回读生成的脱敏快照，不包含姓名、学号、原始答案或树洞正文，也不是实时预警页面。
以 `VITE_ENVIRONMENT_KIND=demo` 构建后台才会开放 `/defense`，仍需现有管理员登录。

如需撤出演示，先保存所需证据，然后使用 `rollback --env-file` 撤回本批次，勿从后台全量重置。
回滚先核对已有文档，删除时再次匹配内容，再回读确认只撤掉该批次。
最后将静态托管恢复到发布前的备份，以同步撤出旧的看板快照。
