# 心语 V2 全局权限矩阵与跨端状态可见性设计方案

## 1. 文档信息

- 建立日期：2026-08-26

- 当前状态：权限等级、任务能力、跨端状态和异常边界已冻结；实现联调与隔离验证待开发阶段执行

本文定义“哪种任务能力可以看到什么、每个状态在哪一端如何表达、哪些操作允许发生”。首轮 W-01 只使用固定账号“心理健康中心工作人员 / 超级管理员”，不提供角色选择或切换；权限仍按任务能力、对象、字段范围、有效期和模式校验。

## 2. 权限原则

V2 使用“隐私梯度 + 最小投影 + 状态合同”：

1. 每类数据只进入必要的业务域；
2. 当前任务只返回完成操作所需的字段；
3. P2/P3 访问绑定对象、理由、期限和审计；
4. 固定演示账号拥有演示能力，不等于拥有全量数据读取；
5. 学生端不显示后台任务、内部判断或处理人；
6. 后台不因“超级管理员”名称绕过最小字段与身份审批。

## 3. 四级可见性

| 等级 | 名称 | 可见范围 |
| --- | --- | --- |
| P0 | 不可见 | 页面、对象和内容均不可见 |
| P1 | 脱敏事实 | 匿名内容、脱敏文本和流程状态 |
| P2 | 受限必要证据 | 当前安全支持任务所需的最小事实 |
| P3 | 短时最少身份 | 审批后、在有效期内查看获批遮罩字段 |

系统不提供默认完整身份访问、永久身份解锁或全域学生档案。P2/P3 每次读取都必须再次鉴权；P3 实际展开单独写入审计。

## 4. 全局数据权限矩阵

| 数据域 | 学生本人 | 内容审核能力 | 安全支持能力 | 跟进记录能力 | 身份授权能力 | 系统维护能力 |
| --- | --- | --- | --- | --- | --- | --- |
| 每日心情 | 本人可见 | P0 | P0 | P0 | P0 | P0 |
| 普通 PHQ-9/GAD-7 结果 | 本人可见 | P0 | P0 | P0 | P0 | P0 |
| 睡眠观察结果 | 本人可见 | P0 | P0 | P0 | P0 | P0 |
| 已公开树洞内容 | 公共可见 | P1 | 绑定任务时按需 P1 | P0 | P0 | 默认 P0 |
| 待处理树洞内容 | 作者看到中性状态 | P1 | 转入任务后 P2 | P0 | P0 | 默认 P0 |
| 受限安全支持任务 | 学生只看到支持路径 | P0 | P2 | 已绑定任务内按需 P2 | 审批所需最小事实 | P0 |
| 真实身份 | 只看到自己的核验状态 | P0 | 获批后 P3 | 获批且必要时 P3 | 审批与获批范围 P3 | 默认 P0 |
| 审计事件 | P0 | 自身能力范围 | 自身能力范围 | 自身能力范围 | 身份相关范围 | 系统事件范围 |

“按需”不是永久授权。固定账号打开不同任务时，仍只能获得该行定义的投影。

## 5. 数据不自动跨端复制

- 每日心情不进入后台，不发送 AI，不触发任务；
- 撤回社区审核同意后仍可浏览树洞，但新增帖子和回应保持不可用，直到重新确认当前版本；
- 普通自测和睡眠观察只属于学生本人；
- 较高分数结果不创建安全支持任务；
- PHQ-9 第 9 题非零但未完成当前安全确认时，不创建后台任务；
- 选择“我现在可以保证安全”不创建后台任务；
- “我不太确定”或“我现在无法保证安全”只在演示/真实授权模式下进入最小安全支持任务；
- 树洞仅在内容审核选择“转安全复核”后进入受限任务；
- 真实身份只在绑定任务的申请被批准后短时出现；
- 审计记录操作事实，不复制完整正文、完整答案、未授权身份或 AI 原始输出。

## 6. 树洞状态映射

| 内部状态 | 作者端 | 内容审核能力 | 安全支持能力 | 公共树洞 |
| --- | --- | --- | --- | --- |
| 未提交 | 仅当前页面 | P0 | P0 | 不显示 |
| 检查中 | 正在检查内容…… | 流程状态 | P0 | 不显示 |
| 已公开 | 已发布到树洞 | 处理结果 | P0 | 正常显示 |
| 保护展示 | 正文已受到保护 | 保护决定 | P0 | 默认折叠 |
| 等待确认 | 内容正在等待进一步确认 | 进入待处理任务 | 未转交时 P0 | 不显示 |
| 未公开 | 这段内容没有公开 | 可见内部理由 | P0 | 不显示 |
| 安全优先 | 先显示支持资源 | 已转交状态 | P2 最小事实 | 不显示 |
| 已删除 | 已删除 | 只保留必要状态 | 活跃任务内最小状态 | 立即消失 |

规则：

- 内容审核最终操作只有公开、保护展示、暂不公开、转安全复核；
- 保护展示只适用于帖子，回应只能公开、暂不公开或转安全复核；
- 暂缓、驳回、隐私残留、规则不符和信息不足只作为“暂不公开”的内部理由；
- 等待确认、未公开和安全优先内容不在公共树洞占位；
- 学生端不显示内部理由、AI 命中、任务编号或处理人；
- 自动检查失败进入等待确认，不能默认公开。

## 7. 自测与安全状态映射

| 状态 | 学生端 | 后台 |
| --- | --- | --- |
| 普通完成 | 普通结果页 | 不创建安全支持任务 |
| 较高分数完成 | 支持资源前置的较高分数结果 | 不创建安全支持任务 |
| 第 9 题非零且能保证安全 | 按固定规则完成结果 | 不创建安全支持任务 |
| 第 9 题非零且不太确定 | 支持资源优先，可自主继续 | 演示/授权模式可记录最小任务 |
| 第 9 题非零且无法保证安全 | 只显示现实支持、离开和修改答案 | 演示/授权模式可记录最小事件，不生成完整结果 |
| 未完成安全确认 | 不计算完整结果 | 不创建任务 |

安全支持能力只可见来源、当前安全确认选择、已展示资源类别、完成状态、进入时间和任务状态；不得读取完整答案、总分、其他自测、历史、AI 或默认身份。

## 8. 身份状态映射

学生身份核验与后台身份授权是两个流程：

- 学生端：未开始、核验中、失败、完成；
- 后台申请：未申请、待审批、已批准、已拒绝、已过期、已撤回；
- 批准前：P0，不显示身份字段；
- 批准后：仅显示申请范围内的遮罩字段；
- 到期或撤回：立即回到 P0；
- 学生端不显示谁申请、谁批准、谁查看或后台任务是否存在。

身份授权必须绑定受限任务、事实理由、字段范围和有效期限。不得永久解锁、批量导出、跨对象访问或通过姓名/学号反查社区、自测与心情记录。

## 9. 操作权归属

| 操作 | 发起能力 | 最终决定能力 |
| --- | --- | --- |
| 发布树洞内容 | 学生本人 | 规则检查或内容审核能力 |
| 公开、保护展示、暂不公开 | 内容审核能力 | 内容审核能力 |
| 转安全复核 | 内容审核能力 | 安全支持能力继续处理 |
| 确认支持已提供、转交或结束 | 安全支持能力 | 安全支持能力 |
| 申请查看身份 | 安全支持能力 | 身份授权能力审批 |
| 批准、拒绝、撤回身份访问 | 身份授权能力 | 身份授权能力 |
| 添加和结束跟进记录 | 跟进记录能力 | 当前授权范围内的跟进能力 |
| 修改运行配置和演示重置 | 系统维护能力 | 服务端校验并写入审计 |

任何能力都不能修改学生原始答案、修改学生原文、把内部状态改写成医疗结论、删除审计事件或在演示环境读取真实数据。

## 10. 任务、并发与异常

- 工作任务状态：待处理 → 已认领 → 已提交/已解决，同时允许释放或过期；
- 一个任务只有一个有效认领人；
- 他人已认领时当前详情只读；
- 对象版本变化时显示“这条记录的状态已经变化，当前页面已只读。”；
- 无权限显示“当前账号无法查看这部分内容。”；
- 会话过期显示“登录状态已过期，请重新登录。”并隐藏敏感内容；
- 身份授权过期显示“身份访问授权已过期，请重新申请。”；
- 自动检查失败时，学生端显示等待确认，后台显示“自动检查未完成，请进行人工处理。”；
- 删除后公共正文立即消失，后台只保留允许的最小状态和审计事实。

异常提示不泄露对象是否存在、真实身份、受保护字段或内部安全判断。

## 11. 生命周期与视觉

- 普通记录由学生在本人入口单条管理；
- 等待确认的树洞内容由作者撤回；
- 公开内容删除后立即停止公共展示；
- 活跃受限任务只保存处理所需的最小事实；
- 身份到期或撤回后立即从可见投影移除；
- 审计只读且不能被普通操作覆盖；
- 演示与真实环境使用隔离命名空间。

界面使用纯色背景、细分隔线和清晰状态文字；不使用红黄绿风险图、大面积警报、风险排行、监控大屏或通过颜色单独表达权限。

## 12. 验收

- 固定账号入口不存在角色选择或切换；
- 同一固定账号在不同任务中仍只收到对应能力投影；
- 每日心情、普通自测、睡眠和较高分数不进入后台；
- 内容审核能力看不到受限安全任务和真实身份；
- 安全支持能力只能看到已进入任务的 P2 最小事实；
- P3 必须经过申请、审批、字段限制、有效期限和实际展开审计；
- 树洞状态在作者端、审核端、安全支持端与公共端一致；
- 删除、过期、冲突、无权限和演示模式不会泄露额外内容；
- 每个敏感查看和状态变化均可在 W-05 回溯。
