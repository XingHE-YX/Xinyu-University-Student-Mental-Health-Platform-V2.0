## 2. 冻结策略

V2 采用“双层冻结”：

1. 学生端核心闭环：完整呈现学生自助观察、匿名表达、结果回顾和支持资源；
2. Web 受控演示闭环：完整演示任务能力、内容审核、受限安全支持、身份授权、跟进、待办和审计状态，但不承诺真实学校处置。

第一层保证用户体验完整，第二层保证跨端边界可被验证。两层均使用同一套产品状态和权限原则，但真实数据、真实岗位责任和真实安全响应条件仍需单独授权和核验。

## 3. 第一层：学生端核心闭环

| 范围 | 必须覆盖 |
| --- | --- |
| 首次使用 | 基础同意、身份核验、隐私说明和到达今日 |
| 今日 | 今日状态、每日心情入口、近期观察和自测入口 |
| 自测 | PHQ-9、GAD-7、睡眠自定义观察、退出确认、安全确认 |
| 结果 | 分数、定位尺、回答构成、回答指纹、历史轨迹、AI 辅助文字或固定规则模板 |
| 支持 | 普通支持资源、安全支持优先、必要时隐藏 AI 和历史 |
| 树洞 | 公共浏览、社区规则、发帖、等待确认、保护展示、作者状态和撤回 |
| 我的 | 我的树洞内容、个人记录入口、身份核验状态、数据删除和账户删除确认 |
| 导航 | 今日、自测、树洞、我的四个底部入口 |

学生端不需要为了展示内部处理过程而增加后台术语、风险等级、模型置信度或综合心理健康指标。

## 4. 第二层：Web 受控演示闭环

| 工作域 | 必须能够演示 |
| --- | --- |
| W-01 登录与会话 | 固定账号、演示模式、会话过期、退出；不提供角色选择或切换 |
| 待办 | 需要我处理、等待他人、最近处理、认领和释放 |
| 内容审核 | 脱敏文本、自动检查失败、人工确认、公开/保护展示/暂不公开/转安全复核 |
| 安全支持 | 待确认、支持已提供、等待授权、跟进中、已结束 |
| 身份授权 | 申请、批准、拒绝、短时最少身份、到期和撤回 |
| 跟进 | 记录事实、提交、交接和结束 |
| W-05 审计与重置 | 登录、敏感访问、决定、权限失败、并发冲突、会话过期和演示重置 |

后台演示只使用合成对象和合成身份。它证明的是任务与权限流程，不证明学校已经建立真实响应网络。

## 5. 暂缓和不纳入范围

以下能力不进入本轮 V2：

- 自动联系学校；
- 真实校内心理中心或热线联动；
- 真实响应时限、责任人和升级承诺；
- 学生私信；
- 热度榜、推荐流、内容排名和新闻式信息流；
- 综合心理健康指数、雷达图和红黄绿风险图表；
- AI 计算分数、诊断、判断风险或执行安全处置；
- 永久身份解锁、批量导出和身份反查；
- 学生数据批量导出、一键清空和批量删除；
- 审核申诉与复议工作流；
- 移动端管理员后台；
- 任何以卡片墙、监控大屏或健康画像为主的页面。

这些能力可以在未来重新评估，但不能通过“顺手加入”进入当前原型。

## 6. 演示模式规则

### 6.1 数据隔离

- 演示账号、帖子、答卷、身份和安全支持任务均为合成数据；
- 演示命名空间与真实命名空间完全分离；
- 演示页面从登录开始显示“演示模式”；
- 演示数据可以初始化和重置；
- 演示数据不能通过姓名、学号或对象编号访问真实数据；
- 演示身份字段不代表真实身份。

### 6.2 可演示状态

至少准备以下演示案例：

- 普通 PHQ-9/GAD-7 结果；
- 较高分数但不显示风险等级；
- AI 服务失败后的固定规则结果；
- 树洞正常公开、保护展示、等待确认、未公开和安全优先；
- 内容审核任务认领和并发冲突；
- 安全支持任务待确认、支持已提供、跟进和结束；
- 身份授权批准、短时显示、过期和撤回；
- 无权限、会话过期和审计回溯。

### 6.3 表述边界

演示中的跟进、身份查看和安全支持任务只能描述为模拟流程、受控演示或产品原型，不得描述为真实学校干预、真实危机响应或真实心理诊断。

## 7. 新功能准入条件

新功能只有同时满足以下条件，才可进入当前 V2：

1. 直接服务于自助观察、匿名表达或支持资源；
2. 不扩大身份暴露和后台默认可见范围；
3. 能放入今日、自测、树洞、我的四个导航；
4. 能写入已有状态机和能力投影；
5. 不制造诊断、排名、风险图表或资讯流体验；
6. 能在核心闭环或受控演示中被验收。

不满足条件的功能进入未来清单，并记录暂缓理由。

## 8. 仍需完成的上线配置与验证门槛

范围冻结不代表以下条件已经完成：

- PHQ-9/GAD-7 最终中文版本、授权和专业核验；
- 校内资源、热线和真实安全响应角色；
- DeepSeek API Key、成本和运行参数；
- CloudBase EnvID、小程序 AppID、后台域名、备份与真实环境配置；
- 正式演示脚本、原型截图和验收结论。

基础服务同意通过“账户停止使用”终止继续处理；社区审核同意可在“数据使用与同意”中撤回，撤回后仍可浏览树洞但不能新增帖子或回应，已有内容仍可由本人逐条删除。再次发布前必须重新确认当前版本。数据导出、批量操作和审核申诉不进入 V2，未来如需加入必须重新设计和评审。

睡眠题目和结果规则、AI 模型与提示词、数据库平台、部署方式及同意撤回后的产品行为均已完成设计冻结。以上配置和验证事项不会扩大已确认的产品范围，必须按各自责任在上线前核验或配置。
