## 2. 数据原则

1. 数据只服务于自助观察、匿名表达、必要支持与可追溯处理；
2. 不建立综合心理画像、学生排名或后台健康总览；
3. 跨域关联使用不可逆内部引用，不使用姓名或学号横向串联；
4. 每个端和任务只得到最小字段投影；
5. 原始事实、固定规则结果、AI 辅助、人工决定和审计分别保存；
6. 未提交内容不生成后台对象；
7. 演示与真实授权环境使用隔离命名空间。

## 3. 领域划分

| 数据域 | 保存内容 | 关键边界 |
| --- | --- | --- |
| 身份账户 | 核验状态、内部账户引用、同意版本 | 不向社区和 AI 暴露 |
| 私密观察 | 每日心情 | 仅本人，不触发后台任务 |
| 自测快照 | 固定答案、规则版本、结果快照 | 普通记录仅本人可见 |
| 匿名社区 | 匿名身份快照、帖子、回应、公开状态 | 与真实身份分离 |
| 内容审核 | 脱敏内容、规则结果、人工决定 | 不保存无必要未脱敏副本 |
| 安全支持 | 最小安全事实、已展示资源、受限状态 | 仅演示或授权模式进入后台 |
| 身份授权 | 申请、字段范围、有效期、撤回 | P3 短时最少显示 |
| 工作任务 | 认领、版本、处理状态与交接 | 防止并发覆盖 |
| 审计 | 操作者、能力、对象、动作、结果 | 只读，不复制完整敏感内容 |
| 运行配置 | 支持资源、短句库版本、模型开关 | 分环境管理 |

身份域与其他域只通过不可逆内部引用关联。社区匿名身份不能反向映射真实身份；普通后台也不能通过姓名、学号或对象编号枚举学生全部记录。

## 4. 核心对象

| 对象 | 产品职责 | 默认可见范围 |
| --- | --- | --- |
| 身份账户 | 保存核验状态与同意版本 | 学生本人；身份授权流程按需 |
| 每日心情记录 | 保存当日单次私密心情 | 学生本人 |
| 自测会话 | 承载未完成答题 | 当前学生会话，不写服务端结果 |
| 自测结果快照 | 保存答案、分数、固定文案和版本 | 学生本人 |
| AI 辅助快照 | 保存已校验辅助文字与版本 | 对应结果本人；安全状态不存在 |
| 匿名身份快照 | 固定发布时匿名昵称与头像 | 作者和公开内容 |
| 树洞内容 | 保存原文、脱敏版本和公开状态 | 作者、公共投影或审核投影 |
| 内容审核任务 | 驱动四种内容决定 | 内容审核能力 P1 |
| 安全支持任务 | 驱动最小支持、转交和结束 | 安全支持能力 P2 |
| 身份访问申请 | 限制身份字段、理由和期限 | 申请/审批任务 |
| 跟进记录 | 保存已发生的事实 | 绑定任务内的跟进能力 |
| 工作任务 | 支持认领、处理、释放和冲突 | 当前任务能力 |
| 审计事件 | 记录敏感读取与状态变化 | W-05 按能力只读 |
| 每日短句 | 保存正文、出处、权利和启用状态 | 学生端仅已启用条目 |

自测结果快照必须保存问卷、计分规则、参考分层、固定文案和 AI 提示词/模型版本；历史不按新规则重算，也不重新请求 AI。

## 5. 状态机

### 5.1 每日心情

~~~text
当日未记录 → 保存中 → 已记录
                   ↘ 保存失败
~~~

- 每天只保存一个已确认值；
- 首版当天不提供修改入口；
- 失败不能显示为已保存；
- 不发送 AI，不创建后台任务。

### 5.2 自测会话与结果

~~~text
答题中 → 安全确认（仅 PHQ-9 条件触发） → 普通完成 / 支持优先完成
   └→ 退出并不保存
安全确认无法保证安全 → 支持资源离开 / 返回修改答案
~~~

- 未完成会话不保存答案、总分、结果、历史或后台任务；
- 普通 PHQ-9、GAD-7 和睡眠完成只生成学生结果快照；
- 第 9 题非零但未完成确认，不创建安全支持任务；
- 选择“我现在可以保证安全”，不创建安全支持任务；
- “我不太确定”或“我现在无法保证安全”只在演示/授权模式下记录最小事件；
- 睡眠不生成医学总分或临床等级；
- AI 只在普通/较高分数结果完成固定规则后调用，安全状态不调用。

### 5.3 树洞内容

~~~text
未提交 → 检查中 → 已公开 / 保护展示 / 等待确认 / 未公开 / 安全优先
                                             └→ 已删除或撤回
~~~

- 已公开与保护展示可进入公共流；
- 保护展示只适用于帖子，回应不使用；
- 等待确认、未公开和安全优先不进入公共流；
- 自动检查失败进入等待确认，不默认公开；
- 作者可撤回等待确认内容，可删除已公开或保护展示内容；
- 首版不编辑已提交原文；
- 内容审核最终操作只有公开、保护展示、暂不公开、转安全复核。

### 5.4 安全支持任务

~~~text
待确认 → 支持已提供 → 已结束
   └→ 等待授权 → 跟进中 → 已结束
~~~

- 任务只能来自规定的自测安全分支或树洞“转安全复核”；
- 待确认不代表诊断、危险程度或学校介入；
- 只保存来源、当前确认、已展示资源、时间和必要跟进事实；
- 结束只表示内部记录结束，不表示问题解决或学生恢复；
- 不向学生端显示任务编号、处理人或内部状态。

### 5.5 身份访问

~~~text
未申请 → 待审批 → 已批准 → 已过期 / 已撤回
                └→ 已拒绝
~~~

- 申请绑定任务、理由、字段和期限；
- 批准前不显示身份；
- 批准后只显示获批遮罩字段；
- 实际展开单独审计；
- 到期或撤回立即隐藏；
- 不提供永久解锁、批量导出或身份反查。

### 5.6 工作任务

~~~text
待处理 → 已认领 → 已提交 / 已解决
             └→ 已释放 / 已过期
~~~

- 一个任务只有一个有效认领人；
- 他人已认领时只读；
- 提交携带对象版本，版本变化进入 W-04；
- 会话过期不保存或提交敏感备注；
- 认领、释放、提交、冲突和失败均写入审计。

## 6. 能力投影

| 投影 | 可以包含 | 禁止包含 |
| --- | --- | --- |
| 学生端 | 本人心情、自测、睡眠、作者状态和支持资源 | 后台任务、内部理由、审计、处理人 |
| 公共树洞 | 已公开匿名正文、回应、保护状态 | 非公开内容、身份、私密观察、任务信息 |
| 内容审核 | 脱敏正文、必要上下文、检查状态、可执行决定 | 真实身份、完整自测、未授权安全事实 |
| 安全支持 | 已进入任务的最小安全事实、资源和处理状态 | 完整答卷、总分、其他历史、AI、默认身份 |
| 身份授权 | 申请理由、字段、对象、状态和期限 | 申请外身份、全部业务内容、批量对象 |
| 跟进记录 | 绑定任务中的已确认事实和已完成步骤 | 未绑定对象、诊断、人格判断、原始答案 |
| 审计 | 操作者、能力、对象、动作、理由、时间、模式和结果 | 完整正文、完整答案、未授权身份、AI 原始输出 |

这些投影是独立的产品合同，不是前端从一份全量详情中隐藏字段。

## 7. 业务命令边界

允许的产品命令：

- 获取或保存每日心情；
- 查看同意版本、撤回或重新确认社区审核同意；
- 开始、完成或丢弃自测会话；
- 读取结果、历史和当前支持资源；支持资源必须按环境、当前 resource_set_version、enabled 和 expires_at 过滤；
- 提交、撤回或删除树洞内容；
- 作出内容审核决定；
- 确认支持、记录事实、转交或结束安全支持任务；
- 申请、批准、拒绝、撤回身份访问；
- 添加、提交或结束跟进记录；
- 认领、释放和提交工作任务；
- 读取只读审计和重置演示数据。

共同约束：

- 绑定学生本人身份或当前任务能力；
- 绑定明确对象和当前状态版本；
- 服务端校验权限、模式、状态、字段和幂等；
- 需要理由或确认的操作不得省略；
- 每次敏感读取和状态变化可追溯。

禁止提供通用“更新任意字段”、通过 URL/编号绕过投影、姓名/学号全域搜索、普通高分批量转任务、AI 覆盖固定结果或安全决定、从审计恢复敏感正文，以及演示环境访问真实数据。

## 8. 失败、重复与并发

- 重复提交返回已有结果或当前状态，不生成重复帖子、结果、申请和跟进；
- 对象版本变化显示“这条记录的状态已经变化，当前页面已只读。”；
- 无权限显示“当前账号无法查看这部分内容。”；
- 会话过期显示“登录状态已过期，请重新登录。”并隐藏敏感内容；
- AI 失败时，自测使用固定说明，树洞进入等待确认；
- 支持资源未配置时显示未配置状态，不虚构联系方式；
- 删除后公共正文不可读取，只保留允许的最小状态和审计事实。

## 9. 生命周期

- 每日心情和普通自测可由学生单条删除；
- 树洞公开内容删除后立即停止公开，等待确认内容可撤回；
- 账户停止使用后进入 30 天恢复期；
- 恢复期后按规则清理普通身份、社区和自测数据；
- 活跃安全支持任务的最小记录及依法或按授权保留的审计继续受限保存；
- P3 到期或撤回后立即从可见投影移除；
- 审计事件只读，不由普通业务删除或覆盖；
- 数据删除不承诺立即清除所有备份或法定保留记录。

## 11. UI/UX 验收

- 学生端不出现后台任务、内部理由、能力名称或安全分级；
- 后台 W-02/W-03 使用固定账号和按任务能力的最小投影；
- 安全支持、身份授权和跟进共用 W-03 两栏骨架；
- 冲突、无权限、过期、删除和失败状态有明确去向；
- 普通页面不因后台存在而增加警报颜色、任务数量或风险图表；
- 演示页面持续标明演示模式，且无法查询真实命名空间。
