# 心语 V2 后台 Web 工作台与统一任务详情设计方案

## 1. 文档信息

- 建立日期：2026-08-26
- 收口日期：2026-08-27
- 适用范围：心语 V2 独立桌面 Web 管理后台
- 当前状态：W-01 至 W-05 的页面结构、状态、文案、权限投影和桌面适配已冻结；实现验证待开发阶段执行
- 关联文档：
  - `docs/v2/V2_CONFIRMED_PRODUCT_DECISIONS.md`
  - `docs/superpowers/specs/2026-08-24-admin-control-layer-design.md`
  - `docs/superpowers/specs/2026-08-24-admin-safety-support-identity-followup-design.md`
  - `docs/superpowers/specs/2026-08-26-permission-visibility-matrix-design.md`
  - `docs/superpowers/specs/2026-08-26-audit-demo-data-design.md`

后台与学生端共享后端规则，但使用独立桌面 Web UI。后台不进入微信小程序，不做移动端适配，也不因为演示账号权限较高而扩大每类任务的数据投影。

## 2. 尺寸与后台外壳

- 标准画布：1440×900；
- 最小工作宽度：1280px；
- 低于 1280px：只显示“管理后台请在电脑浏览器中使用”，不加载受保护内容，不压缩成移动端单列；
- 左侧导航约 220px，顶部状态区约 64px；
- 左侧导航只显示“工作台”“审计日志”“退出登录”；
- 页面持续显示当前账号和“演示模式”或“授权模式”。

后台使用纯色背景、文字层级、细分隔线和紧凑列表；不使用数据大屏、效率排行、风险比例、卡片墙或学生端情绪化装饰。

## 3. 页面状态总表

| 编号 | 名称 | 定义 |
| --- | --- | --- |
| W-01 | 固定账号进入 | 预设账号、演示模式、登录中、失败、会话过期 |
| W-02 | 工作台 | 需要我处理、等待他人、最近处理 |
| W-03 | 统一任务详情 | 内容审核、安全支持、身份授权、跟进记录四种变体 |
| W-04 | 异常状态变体 | 他人认领、状态变化只读、无权限、会话过期、提交失败 |
| W-05 | 审计与演示重置 | 只读审计日志、事件详情、重置确认和结果 |

W-04 不是独立业务页面，必须复用 W-03 的详情骨架或全页桌面门槛。W-05 的完整设计见审计与演示数据规范。

## 4. W-01 固定账号进入

页面显示：

```text
心语后台
演示模式

心理健康中心工作人员
超级管理员

进入后台
```

账号显示语义统一为 `心理健康中心工作人员 / 超级管理员`。首轮不提供账号注册、密码找回、角色选择、角色切换或自由输入账号。进入后该账号可处理全部合成演示任务，但：

- 不能读取真实环境；
- 不能通过 URL、搜索或通用接口绕过最小字段投影；
- “超级管理员”不自动获得未审批的 P3 真实身份字段；
- 审计记录统一写入该演示账号及超级管理员权限。

会话过期固定显示：

```text
登录状态已过期，请重新登录。
```

过期状态不继续显示敏感内容，未提交备注不保存在浏览器本地。

## 5. W-02 工作台

### 5.1 页面结构

1440px 画布下，主体采用横向三个连续文字区块，使用细竖线分隔：

```text
需要我处理　│　等待他人　│　最近处理
```

第一栏承担主要视觉权重，不制作统计卡片、数字总览或效率排行。顶部只提供任务类型、状态和时间的轻量文字筛选。

### 5.2 区块定义

- `需要我处理`：固定账号可以认领并提交决定的任务；
- `等待他人`：正在由其他处理流程确认、等待补充或已被他人认领的任务；
- `最近处理`：固定账号近期完成或结束的任务，只读查看。

任务类型固定为：

- 内容审核；
- 安全支持；
- 身份授权；
- 跟进记录。

任务行只显示：

- 任务类型；
- 对象编号；
- 脱敏来源；
- 进入时间；
- 当前状态；
- `开始处理` 或 `查看`。

不显示学生姓名、学号、完整正文、完整答卷、PHQ-9 总分、风险等级、AI 置信度、支持数量或处理倒计时。

### 5.3 状态

- 空状态：“暂时没有需要你处理的记录／可以查看最近处理”；
- 未认领：“开始处理”；
- 他人处理中：“这条记录正在由其他审核员处理”；
- 已完成：“查看处理记录”；
- 列表加载失败：“暂时没有加载到任务，请重新尝试”。

任务列表在当前阅读期间不自动重排。用户主动刷新后更新；从详情返回时保留筛选与滚动位置。

## 6. W-03 统一任务详情

### 6.1 固定骨架

所有任务使用两栏结构：

```text
任务类型 / 对象编号 / 当前状态

必要事实与脱敏内容       当前操作
```

左栏承载任务所需的最小事实，右栏承载认领、操作选项、理由、提交和状态反馈。任务类型只替换字段和按钮，不重新设计页面，不提供通用字段编辑、批量操作或三栏数据面板。

### 6.2 内容审核变体

左栏显示：

- 脱敏树洞正文；
- 帖子或回应；
- 话题；
- 发布时匿名身份；
- 自动检查状态；
- 必要上下文；
- 当前公开状态。

右栏最终操作固定为：

- 公开；
- 保护展示；
- 暂不公开；
- 转安全复核。

保护展示只适用于帖子；回应选择同类建议时必须改为暂不公开或人工确认。`暂缓`、`驳回`、`隐私残留`、`规则不符`、`信息不足`只作为“暂不公开”的内部理由，不再成为额外公开状态。敏感决定必须填写简短事实理由，理由只用于内部审计。

自动检查失败固定显示“自动检查未完成，请进行人工处理”，内容保持不公开，不能默认发布。普通内容审核不显示风险等级、AI 推理链、置信度、原始命中词、未脱敏原文或真实身份。

### 6.3 安全支持变体

左栏只显示：

- 来源类型；
- 最小安全事实；
- 用户当前确认选择；
- 已展示给学生的支持资源类别；
- 当前受限状态；
- 必要的授权跟进事实。

右栏操作：

- 确认支持已提供；
- 记录一次事实跟进；
- 转交授权负责人；
- 结束本次支持记录。

不显示完整 PHQ-9 答案、总分、其他自测、历史轨迹、AI 解读或默认真实身份。“我现在可以保证安全”不创建该任务；只有“我不太确定”和“我现在无法保证安全”在演示环境或真实授权模式下可以进入。树洞来源只能由人工 `转安全复核` 进入。

### 6.4 身份授权变体

左栏显示申请对象编号、绑定的受限任务、申请理由、请求字段、有效期限、当前状态和审计摘要。批准前不显示真实身份；批准后只在有效期内显示遮罩姓名、学号后四位等获批最少字段。

右栏操作：

- 批准；
- 拒绝；
- 撤回授权。

页面持续显示“本次身份访问将在规定时间后失效”。每次展开受限字段都单独写入审计。固定演示账号的超级管理员权限不能跳过申请、字段范围、有效期或查看审计。

### 6.5 跟进记录变体

左栏显示当前状态、已确认事实、已完成步骤、仍需补充的事实和记录时间。右栏操作为保存跟进记录、提交、结束跟进。

跟进记录只能描述已经执行或确认的事实，不得填写诊断、人格判断、未经证实的推断，不得改写学生原文、原始答案或安全确认。演示环境只能写“演示跟进”“模拟转交”等明确表述。

## 7. 认领、提交与并发

任务流程固定为：

```text
待处理 → 已认领 → 已提交 / 已解决
```

- 点击 `开始处理` 后才启用右栏表单；
- 他人已经认领时只读，不提供强行接管；
- 提交前显示当前公开状态、安全状态、身份状态和审计结果预览；
- 提交请求携带对象状态版本；
- 另一个处理人或作者先改变状态时，当前页面切换为 W-04 只读状态；
- 浏览器返回或会话过期不自动保存敏感备注。

## 8. W-04 异常状态变体

### 8.1 他人已认领

```text
这条记录正在由其他审核员处理。
```

详情只读，不显示对方的未提交备注，不提供接管。

### 8.2 状态变化

```text
这条记录的状态已经变化，当前页面已只读。
```

显示最新可见状态和返回工作台；不得覆盖新状态。

### 8.3 无权限

```text
当前账号无法查看这部分内容。
```

不说明被保护对象是否存在，不泄露字段名、身份、正文或安全事实。该状态用于演示真实权限边界。

### 8.4 会话过期

隐藏详情并显示“登录状态已过期，请重新登录”。重新进入后必须重新通过权限检查。

### 8.5 提交失败

保留当前已输入但未持久化的表单状态，只显示“暂时没有提交成功，请确认后重试”；不得显示为已完成。若重新读取发现状态已改变，转为只读冲突。

## 9. W-05 入口关系

左侧“审计日志”进入 W-05。W-05 只读，不从日志重新执行决定；演示重置是 W-05 中的独立二次确认操作，只作用于演示命名空间。审计事件、筛选、重置和 AI 回退见 `2026-08-26-audit-demo-data-design.md`。

## 10. 权限与数据边界

- 固定账号可以访问所有演示任务，不代表真实环境只有一个角色；
- 真实权限仍按内容审核、安全支持、身份授权、跟进和系统维护能力拆分；
- 页面只按任务类型投影最小字段，不通过切换角色改变布局；
- P3 身份字段必须独立申请、审批、限时查看和审计；
- 演示数据与真实数据使用不同环境和命名空间；
- 后台不能按姓名、学号或正文关键词浏览全量学生资料；
- 审计日志不可修改或删除。

## 11. 验收条件

- W-01 只显示固定账号，不出现角色选择或切换；
- W-02 始终为三个任务区块且不使用统计卡；
- W-03 四种任务共用同一两栏骨架；
- 内容审核只有四个最终操作；
- “我现在可以保证安全”不创建安全支持任务；
- W-04 所有状态不泄露受保护内容且不能覆盖新状态；
- W-05 只读，演示重置不影响真实数据；
- 1280px 与 1440×900 下操作区稳定；
- 低于 1280px 不显示受保护详情；
- 会话过期后未提交敏感输入不落地。
