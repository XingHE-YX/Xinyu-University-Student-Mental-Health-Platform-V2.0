# 心语 V2 后台基础控制层设计

## 1. 文档信息

- 建立日期：2026-08-24
- 收口日期：2026-08-27
- 适用范围：后台账号会话、工作任务、权限投影、通知、并发与审计入口
- 当前状态：固定演示账号、控制层状态和安全边界已冻结；真实组织角色与响应责任属于上线授权门槛

本规范定义后台控制层，不改变 W-01 至 W-05 的页面架构。完整页面见 `2026-08-26-admin-workbench-unified-task-design.md`。

## 2. 控制层目标

后台必须保证：

- 当前账号、模式和会话状态明确；
- 每个任务只投影最小必要字段；
- 任务认领、提交和冲突不会互相覆盖；
- 身份访问与普通内容审核分离；
- 演示数据与真实数据隔离；
- 敏感访问和状态改变可审计；
- AI、网络或会话失败时不越权、不默认公开、不伪造成功。

## 3. W-01 账号与会话

首轮只使用固定预设账号：

```text
心理健康中心工作人员 / 超级管理员
```

不提供管理员注册、密码找回、角色选择或角色切换。固定账号可以处理全部合成演示任务，但后端仍按任务类型投影最小数据；“超级管理员”不等于自动读取全部学生记录或未审批身份。

真实授权环境未来可以把内容审核、安全支持、身份授权、跟进和系统维护分配给不同人员，但该组织配置不改变 W-01 至 W-05 页面结构，也不在当前演示入口中增加角色选择。

会话状态：

| 状态 | 表达 |
| --- | --- |
| 未登录 | 显示固定账号与进入操作 |
| 登录中 | 正在进入后台，请稍候 |
| 登录失败 | 暂时无法进入，请重新尝试 |
| 已登录 | 持续显示账号与演示/授权模式 |
| 会话过期 | 登录状态已过期，请重新登录 |

会话过期后立即隐藏受保护内容；未提交的审核理由、身份申请和跟进备注不保存在浏览器本地。

## 4. 权限能力

真实系统按能力控制，而不是依赖前端角色名称：

| 能力 | 可见数据 | 可执行动作 |
| --- | --- | --- |
| 内容审核 | P1 脱敏树洞事实 | 公开、保护展示、暂不公开、转安全复核 |
| 安全支持 | P2 最小安全事实 | 确认支持、转交、记录事实、结束 |
| 身份授权 | 申请与字段范围 | 批准、拒绝、撤回、限时查看 |
| 跟进记录 | 已授权安全支持任务事实 | 添加事实记录、提交、结束 |
| 系统维护 | 运行配置与演示状态 | 重置演示、维护配置；不默认浏览内容或身份 |

固定演示账号拥有这些演示能力，但每次请求仍必须检查：当前环境、对象模式、能力、对象状态版本和字段范围。前端隐藏按钮不是权限控制。

## 5. W-02 工作任务

工作任务统一投影到：

- 需要我处理；
- 等待他人；
- 最近处理。

任务行只显示任务类型、对象编号、脱敏来源、进入时间、状态和操作。不显示完整正文、真实身份、完整答卷、风险等级或 AI 置信度。

工作任务状态：

```text
待处理 → 已认领 → 已提交 / 已解决
                 ↘ 状态冲突 / 提交失败
```

认领只授予当前处理权，不扩大数据权限。任务被他人认领时只读；状态已变化时使用对象版本阻止覆盖。

## 6. 轻量工作提醒

后台可提供低强调度的“工作提醒”，只用于：

- 新任务进入；
- 已认领任务状态变化；
- 身份授权到期或撤回；
- 系统或 AI 回退状态。

提醒预览不显示姓名、学号、树洞正文、完整安全证据、完整自测答案或 AI 摘要。点击后仍需重新检查环境、会话和权限。首版不做推送中心、跳动红点、声音提醒、响应倒计时或效率指标。

## 7. 并发与未提交内容

- 所有状态改变请求携带对象当前版本；
- 服务端先检查认领人、权限、模式和版本，再改变状态；
- 冲突时返回最新可见状态，页面切换为只读；
- 不允许强行接管或最后写入覆盖；
- 页面刷新、返回、退出和会话过期不自动提交；
- 未提交敏感输入不写入浏览器持久存储；
- 提交失败可以在当前会话中保留输入供重试，但不能显示为已完成。

## 8. 身份访问控制

真实身份与内容、私密观察和匿名社区分域保存。身份访问必须：

1. 绑定一个已进入受限安全流程的对象；
2. 填写事实理由；
3. 选择最少字段和有效期；
4. 经过独立批准；
5. 每次实际展开字段都写审计；
6. 到期或撤回后立即隐藏。

“超级管理员”不跳过上述步骤。普通内容审核不能申请或查看身份；后台不提供按姓名、学号浏览学生或通过身份反查树洞的通讯录。

## 9. 演示与真实模式

- 演示模式持续显示在 W-01 至 W-05；
- 演示与真实授权模式使用不同 CloudBase 环境、密钥、数据库命名空间和入口；
- 固定账号只属于演示环境；
- 演示中的身份、跟进、支持资源和审计都是合成数据；
- 演示任务不能触发真实电话、短信、学校系统或身份核验；
- 真实授权未完成时，生产入口保持未配置或不可进入。

## 10. 审计入口

W-05 记录登录、退出、会话过期、认领、审核决定、安全支持、身份申请/批准/实际查看、跟进、权限失败、冲突、删除、演示重置和 AI 回退。日志只读，不复制完整正文、完整答案、未授权身份或 AI 原始内容。

普通筛选、页面跳转和一般列表浏览不进入敏感审计。详细规则见 `2026-08-26-audit-demo-data-design.md`。

## 11. 失败状态

| 失败 | 处理 |
| --- | --- |
| 会话过期 | 隐藏详情，要求重新进入 |
| 无权限 | 只显示“当前账号无法查看这部分内容” |
| 他人认领 | 只读，不泄露对方备注 |
| 状态冲突 | 显示最新事实，禁止覆盖 |
| 保存失败 | 不显示成功，允许确认后重试 |
| AI 失败 | 固定规则或人工确认接管 |
| 演示重置失败 | 不影响真实数据，不宣称全部成功 |

## 12. 验收条件

- W-01 不出现角色选择或切换；
- 固定账号不能读取真实环境；
- 页面按钮、接口和数据库规则使用同一权限边界；
- 超级管理员不能绕过 P3 申请与实际查看审计；
- 任务认领和对象版本可以阻止并发覆盖；
- 会话过期后受保护内容与未提交备注不可见；
- 提醒不泄露敏感正文或身份；
- 演示与真实环境隔离；
- W-05 只读且记录必要敏感事件。
