# 心语 V2 首批高保真页面线框设计方案

## 1. 文档信息

- 建立日期：2026-08-26
- 适用范围：心语 V2 学生端微信小程序首批高保真原型
- 当前状态：页面状态、每日心情弹层、逐屏结构和高保真设计已冻结；真实实现与多尺寸验证待开发阶段执行

本文将已冻结的“暖雾纸白 × 静谧青”首发视觉落实为少量页面线框，不涉及代码或真实身份核验接入。

## 2. 统一画布

首轮优先使用 375×812 画布，同时检查 360px、393px 和系统字体放大状态。

- 页面背景：暖雾纸白；
- 正文：深灰绿；
- 主操作：静谧青；
- 左右留白：20px；
- 393px 及以上左右留白：24px；
- 页面标题：22px；
- 正文：16px；
- 辅助文字：14px；
- 主按钮高度：48px；
- 主要热区：不小于 44px；
- 页面间距：8/12/16/24/32px。

不使用渐变、纹理、噪点、发光、阴影堆叠、卡片墙或庆祝动效。

## 3. 首次使用与基础同意

页面结构：

顶部留白 → 标题 → 说明 → 四行边界 → 同意确认 → 完整说明 → 主操作 → 暂不使用。

标题：

先从今天开始

核心说明：

心语帮助你记录最近的感受，做一些自我观察，也可以在树洞里匿名说说话。

这里的内容用于自我了解，不替代专业诊断。

边界：

- 每日记录默认只属于你自己；
- 树洞使用匿名身份；
- 自测结果用于观察，不代表诊断；
- 你可以管理或删除自己的记录。

操作：

- 我已阅读并了解以上说明；
- 查看完整说明；
- 继续；
- 暂不使用。

页面不使用轮播、插画、真实姓名或注册奖励。

## 4. 身份核验

标题：

先确认这是你的记录

说明：

身份核验只用于保存你的记录、区分账户和处理数据管理请求。

它不会显示在公共树洞中，也不会作为树洞署名。

状态：

| 状态 | 文案 | 操作 |
| --- | --- | --- |
| 未开始 | 先确认这是你的记录 | 开始核验 |
| 核验中 | 正在确认记录归属，请稍候。 | 不重复提交 |
| 失败 | 暂时没有完成核验，请重新尝试。 | 重新核验 |
| 完成 | 已确认这是你的记录。 | 进入心语 |

不显示真实身份详情、倒计时、后台审核、风险标签或复杂进度条。

## 5. 今日页未记录

页面结构：

今日 → 日期 → 时段问候 → 短句 → 此时此刻 → 最近的自我观察 → 树洞与支持资源 → 底部导航。

示例：

今日

2026 年 8 月 26 日

下午好

今天，也可以先从一点点开始。

此时此刻

还没有记录此刻

记录此刻 >

最近的自我观察

- 情绪状态　尚未记录 >
- 焦虑状态　尚未记录 >
- 睡眠与恢复　尚未记录 >

页面末尾：

- 想找个地方说说？／去树洞坐一会儿 >
- 需要支持？／查看支持资源 >

今日　自测　树洞　我的

不显示心理分数、连续天数、健康判断、风险状态或大型图表。

## 6. 今日页已记录

将此时此刻区块替换为：

此时此刻

今天的心情：疲惫／已记录

记录于 14:32

再看一眼 >

其余结构与未记录状态一致。已记录状态不使用庆祝动画、打卡反馈、好坏颜色或状态评级。

## 7. 每日心情弹层

点击记录此刻后，从底部展开：

此时此刻

你的心情更接近哪一种？

愉快　　平静

疲惫　　焦虑

低落　　烦躁

稍后再说

选择后显示确认状态：

已记下此刻

{心情}

再看一眼

规则：

- 六种心情只使用文字表达；
- 选择后保存为私密记录；
- `再看一眼` 关闭确认浮层并回到今日；
- 不自动填充心情、不自动选择话题、不自动发布；
- 稍后再说只关闭弹层；
- 当天不再自动弹出；
- 每日心情不发送给 AI，不触发后台预警。

## 8. 跳转关系

基础同意 → 身份核验 → 今日未记录。

今日未记录 → 每日心情弹层 → 今日已记录。

今日 → 自测、树洞或我的。

首次使用和身份核验隐藏底部导航；今日页显示底部导航。

返回或保存后保留来源和页面状态；重复点击今日不强制回到顶部。

## 9. 验收条件

- 375px 首屏能看到主要操作；
- 360px 无横向溢出；
- 393px 及字体放大后仍可读；
- 首次使用不变成长协议或轮播；
- 身份核验不产生监控感；
- 今日页不空洞、不拥挤、不像任务面板；
- 未记录和已记录状态不依赖颜色即可区分；
- 每日心情保存后状态立即明确；
- 页面没有渐变、卡片墙、发光或庆祝动画；
- 同一套线框可以复用于自测、树洞和我的。

## 10. 第一批逐屏高保真细化（已确认方案）

### 10.1 首次使用

375×812 画布中，页面顶部保留较大留白，正文依次为“先从今天开始”、产品说明、四行边界、同意勾选、完整说明入口、继续和暂不使用。主操作不悬浮固定，跟随内容自然落在页面底部。

未勾选“我已阅读并了解以上说明”时，“继续”保持低强调状态且不可进入身份核验；勾选后只改变勾选标记和文字层级，不播放庆祝反馈。首次使用不显示底部导航、真实姓名、注册奖励或轮播。

### 10.2 完整说明弹层

点击“查看完整说明”打开底部说明弹层，弹层使用纯色背景和细线顶部分隔，内容分为每日记录、自测结果和树洞三组。底部提供“我知道了”，点击遮罩、返回或该操作均回到首次使用页，不跳转到独立帮助中心。

说明使用“用于自我了解”“不替代专业诊断”“默认只属于你自己”等已确认边界，不使用绝对化隐私承诺。

### 10.3 身份核验

身份核验页使用“先确认这是你的记录”和固定说明。未开始状态提供“开始核验”；核验中只显示“正在确认记录归属，请稍候。”，禁用重复提交，不显示倒计时或复杂进度条；失败状态显示“暂时没有完成核验，请重新尝试。”和“重新核验”；完成状态显示“已确认这是你的记录。”和“进入心语”。

身份核验不显示真实身份详情、学校名称、后台审核术语、风险标签或具体匹配错误。首次使用和身份核验阶段隐藏底部导航，完成后才进入带底部导航的今日页。

### 10.4 今日未记录

今日页采用“今日/日期/时段问候/短句 → 此时此刻 → 最近的自我观察 → 树洞与支持资源 → 底部导航”结构。“记录此刻”使用 48px 高的连续操作行，以静谧青文字和右箭头强调，不制作大面积填充按钮。

“最近的自我观察”使用情绪状态、焦虑状态、睡眠与恢复三条列表行，均显示“尚未记录”。页面不显示心理分数、连续天数、健康判断、风险状态或大型图表。

### 10.5 每日心情弹层

点击“记录此刻”后，从底部展开“此时此刻”弹层，以两列文字选项展示愉快、平静、疲惫、焦虑、低落和烦躁，并提供“稍后再说”。选择并保存成功后在同一弹层切换为“已记下此刻／{心情}／再看一眼”。

心情只保存为私密每日记录，不发送给 AI、不触发后台任务、不自动关联自测或树洞。“再看一眼”关闭确认浮层并回到今日；“稍后再说”关闭初始浮层且不写入记录。

### 10.6 今日已记录与失败

已记录状态只替换“此时此刻”区块，显示“今天的心情：{心情}／已记录”“记录于 {时间}”和“再看一眼”。不使用连续打卡、庆祝动画、好坏颜色或状态评级。

今日已记录后，首轮原型不提供当天修改入口，只保留“再看一眼”回顾操作，不额外生成连续记录或第二条历史。保存失败时显示“暂时没有记下这次选择”和“重新试试”，保留当前页面内容。

### 10.7 返回与首轮评审

说明弹层关闭后回到原页面；身份核验完成后进入今日；心情保存后回到今日原位置；系统返回不重复提交、不清空已经显示的状态。第一批评审重点是页面留白、今日页内容密度、身份核验的信任感和“记录此刻”操作行是否足够清楚。

## 11. M-01 至 M-05 实际高保真画面细化（已确认方案）

### 11.1 统一画布

第一批优先使用 375×812 画布，内容左右留白 20px；同时检查 360px、393px 和系统字体放大。页面背景为暖雾纸白纯色，正文为深灰绿，主操作为静谧青，圆角不超过 8px，主要操作高度 48px，主要热区不小于 44px。

首次使用、说明弹层和身份核验不显示底部导航；进入今日后显示“今日/自测/树洞/我的”。

### 11.3 M-02 关于心语说明弹层

今日页采用“今日/日期/时段问候/短句 → 此时此刻 → 最近的自我观察 → 树洞与支持资源 → 底部导航”结构。“记录此刻”使用 48px 高连续操作行，以静谧青文字和右箭头强调。

### 11.7 第一批交互与验收

第一批必须可点击走通 M-01 → M-02 → M-03 → M-04 → M-05 → M-04 已记录。说明弹层关闭后回到原页面，核验完成后进入今日，心情保存后回到今日原位置。重点检查页面密度、留白、操作行识别、字体放大和状态是否不依赖颜色。
