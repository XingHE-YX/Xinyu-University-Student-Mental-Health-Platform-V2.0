## 1. 文档信息

- 建立日期：2026-08-26

- 当前状态：页面模板、页面内状态和主要跳转关系已冻结；实现与运行验证待开发阶段执行
- 关联文档：

本文以一人开发能够稳定完成为前提，优先减少页面、路由和重复实现，不改变已经确认的隐私、安全和视觉边界。

## 2. 简化原则

1. 四个底部导航是学生端唯一一级入口；
2. 同一任务的不同状态在同一页面内表现；
3. 只有任务边界或隐私边界改变时才进入新页面；
4. 复杂流程优先使用页面内区块、底部弹层和确认弹层；
5. 视觉层级和状态文案保持统一，不用增加页面数量解决信息组织问题；
6. 优先保证能够完整运行，再考虑深层筛选、批量操作和高级设置。

## 3. 学生端页面模板

### 3.1 主页面

| 编号 | 页面模板 | 承担内容 |
| --- | --- | --- |
| S-01 | 今日 | 今日状态、每日心情入口、近期观察、自测入口 |
| S-02 | 自测 | 三项自测入口、近期记录、历史记录、回顾入口 |
| S-03 | 树洞 | 公共浏览、空状态、内容详情入口、发帖入口 |
| S-04 | 我的 | 我的树洞内容、个人记录入口、身份状态、数据管理 |

四个主页面都显示底部导航。重复点击当前导航不强制回到顶部，切换页面保留各自滚动位置。

### 3.2 必要嵌套页面

| 编号 | 页面模板 | 页面内状态 |
| --- | --- | --- |
| S-05 | 首次使用流程 | 基础同意、隐私说明、身份核验、完成或失败 |
| S-06 | 统一答题页 | PHQ-9、GAD-7、睡眠、答题中、退出确认、提交中 |
| S-07 | 统一结果页 | 普通、较高分、AI 失败、PHQ-9、GAD-7、睡眠 |
| S-08 | 支持资源页 | 普通支持、安全支持、紧急资源、返回来源 |
| S-09 | 发帖页 | 编辑中、提交中、等待确认、未公开 |
| S-10 | 内容详情页 | 公共内容、保护展示、作者状态、回复 |

这些页面隐藏底部导航，使用带文字的返回入口。

### 3.3 页面内状态和弹层

以下内容不单独建立页面：

- 每日心情记录；
- 社区规则和匿名说明；
- 自测退出确认；
- 安全确认；
- 删除内容、撤回内容和账户删除确认；
- 撤回社区审核同意确认；
- 我的树洞内容列表；
- 自测历史记录；
- 无权限、状态冲突、会话过期和提交失败；
- 结果页回答构成展开。

## 4. 学生端主要跳转

首次使用：

首次使用流程 → 今日。

今日：

今日 → 每日心情状态 → 今日；

今日 → 自测 → 统一答题页 → 安全确认状态 → 统一结果页；

统一结果页 → 支持资源页 → 返回原来源；

今日 → 树洞 → 首次进入时显示社区规则 → 树洞公共页；

今日 → 我的。

自测：

自测 → 统一答题页 → 统一结果页 → 返回自测；

自测 → 近期记录或历史记录状态 → 统一结果页；

睡眠、PHQ-9 和 GAD-7 使用同一答题页和结果页模板，只切换模块内容。

树洞：

树洞公共页 → 内容详情页 → 回复状态 → 内容详情页；

树洞公共页 → 发帖页 → 提交完成 → 我的；

我的 → 我的树洞内容状态 → 内容详情页；

等待确认、未公开和安全优先状态只在作者入口显示，不进入公共树洞。

我的：

我的 → 我的树洞内容；

我的 → 数据管理 → 删除确认弹层 → 当前页面显示结果；

我的 → 数据使用与同意 → 撤回社区审核同意 → 社区发布关闭；

我的 → 账户删除确认 → 完成说明。

## 5. 后台 Web 页面模板

### 5.1 页面范围

| 编号 | 页面模板 | 承担内容 |
| --- | --- | --- |
| W-01 | 固定账号进入 | 预设账号、演示模式、登录失败、会话过期 |
| W-02 | 工作台 | 需要我处理、等待他人、最近处理 |
| W-03 | 统一任务详情 | 内容审核、安全支持、身份授权、跟进记录 |
| W-04 | 异常状态变体 | 他人认领、状态只读、无权限、会话过期、提交失败 |
| W-05 | 审计与演示重置 | 只读日志、事件详情、演示数据重置 |

内容审核、安全支持、身份授权和跟进不分别制作四套详情页面，而是在统一任务详情中按任务类型显示最小字段和对应操作。

### 5.2 后台跳转

固定账号进入 → 工作台 → 统一任务详情 → 处理并提交 → 工作台；

工作台或统一任务详情 → 审计日志，只读查看操作记录；

任务被其他人认领、状态已经变化或权限不足时，当前详情页直接切换为只读状态；

会话过期时保留当前页面背景，但显示重新登录提示，不新增错误页面。

## 6. 返回和状态规则

### 6.1 返回规则

- 从结果页返回自测页；
- 从支持资源页返回进入支持前的来源；
- 从发帖页提交后进入我的树洞内容；
- 从公共详情返回树洞公共页；
- 从作者详情返回我的树洞内容；
- 删除完成后回到原列表并显示状态变化；
- 取消确认返回当前任务，不清空已经保存的合法数据。

### 6.2 页面内状态规则

页面状态优先使用标题、说明、按钮和分隔区域表达，颜色只作为辅助。普通、较高分、AI 失败和等待状态不通过新增页面制造差异。

安全支持状态是唯一需要明显改变信息排序的状态：支持资源先出现，必要时隐藏 AI 和历史内容，但仍然沿用同一套页面背景和文字系统。

### 6.3 错误和冲突规则

- 无权限：“当前账号无法查看这部分内容。”
- 状态冲突：“这条记录的状态已经变化，当前页面已只读。”
- 会话过期：“登录状态已过期，请重新登录。”
- 删除完成：“这条内容已删除，不再公开显示。”
- 自动检查未完成：“内容正在等待进一步确认。”

这些提示直接出现在当前页面，不制作错误专页，也不透露受保护对象的额外信息。

## 7. 首版页面边界

首轮原型和实现只需要完成：

- 4 个学生端主页面；
- 6 个必要学生端嵌套/任务页面；
- W-01 至 W-05 五类后台页面状态；
- 已确认的关键状态；
- 主要跳转、返回和删除确认；
- 演示模式和合成数据。

首轮不做：

- 每个状态独立路由；
- 独立的多层设置中心；
- 复杂搜索、批量导出和批量处理；
- 学生私信；
- 移动端后台；
- 高级数据大屏；
- 为未来学校联动预留复杂页面。

## 8. 设计收口

上述页面、状态和跳转已完成设计收口。本文不规定后续开发顺序、分支、提交、测试或任务拆分方式；这些内容等待用户提供开发流程后再建立。
