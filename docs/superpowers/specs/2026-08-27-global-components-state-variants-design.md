# 心语 V2 全局基础组件与状态变体规范

## 1. 文档信息

- 建立日期：2026-08-27
- 适用范围：心语 V2 学生端微信小程序、独立 Web 管理后台和首轮高保真原型
- 当前状态：基础组件、状态词典、页面组合和首轮限制已冻结；实现复用验证待开发阶段执行
- 关联文档：
  - docs/v2/V2_CONFIRMED_PRODUCT_DECISIONS.md
  - docs/superpowers/specs/2026-08-26-visual-baseline-first-prototype-design.md

本文以单人开发为前提，控制组件数量，用少量稳定组件覆盖全部页面，不建立复杂设计系统。

## 2. 组件原则

1. 组件服务内容，不制造装饰；
2. 同一状态在不同页面使用同一种表达；
3. 状态不能只依靠颜色；
4. 只有页面结构确实不同才新增组件；
5. 首轮优先保证复用、可读和容易回归。

## 3. 学生端基础组件

### 3.1 页面顶栏

统一承载返回、页面标题、退出自测和模块名称。顶栏不放分享、通知红点、AI 图标或装饰入口。

### 3.2 底部导航

固定为“今日/自测/树洞/我的”，当前项使用静谧青文字或细线标识，不显示数字角标。首次使用、身份核验、答题、详情、支持资源和删除确认隐藏底部导航。

高保真画面中四项使用太阳、清单、树洞气泡和用户四个线性图标。图标使用固定槽位，与文字采用纵向居中排列，四个导航项的图标中心、文字中心和图标与文字间距保持一致；当前项只通过静谧青与字重区分，不改变布局。

### 3.3 页面引导区

由页面标题和一至三行说明组成，用于今日、自测中心、树洞和支持资源，不使用宣传式副标题或大面积插画。

### 3.4 连续列表行

用于自测模块、今日观察、树洞内容、我的、支持资源、数据管理和账户设置。行高约 72–80px，使用文字、状态和细线分隔，不使用独立卡片背景。

### 3.5 连续操作行

用于“记录此刻”“写下此刻”“查看支持资源”等入口，高度约 48px，使用静谧青文字和右箭头，不制作悬浮按钮或大面积填充。

### 3.6 主要按钮

只用于继续、完成记录、发布、提交等关键动作，高度 48px。按钮文字使用明确动作；不可用、提交中、完成和失败均同时使用文字与交互状态表达。

### 3.7 选项行

用于答题、心情和话题选择。选中状态同时改变标记、文字层级、极浅同色面和边界，不依赖颜色单独传达。

话题选择使用底部单选层，不制作横向标签墙。首版固定提供学业压力、人际关系、家庭与成长、未来选择、日常心情和说不清六项；未选择话题时，发帖按钮保持不可用，选择后将话题回填到编辑页并启用发布。

### 3.8 底部弹层

用于完整说明、心情、话题、删除、退出和匿名身份选择。弹层使用纯色背景、细线顶部分隔和不超过 8px 的圆角；关闭后回到原页面和原位置。

### 3.9 状态提示行

用于保存失败、加载失败、AI 回退、内容可能不是最新和只读冲突。提示直接说明事实，不显示接口错误、命中词或警报式大色块。

### 3.10 文本输入区

用于树洞发帖和回应。只支持纯文本，自然换行，显示字数，输入内容和话题未完成时不启用发布。

### 3.11 折叠区

用于回答构成、完整说明、保护展示正文和数据说明。内容在原位置展开，同一时刻最多展开一项，不跳转新页面。

### 3.12 图表区

只保留分数定位尺、回答指纹、历史轨迹和睡眠观察线四种固定图形。首轮只验证静态结构和合成数据，不使用风险色阶、综合指数、复杂图例或高级动效。

## 4. Web 基础组件

### 4.1 后台外壳

左侧导航加右侧内容区，左侧约 220px，顶部状态区约 64px。导航只保留工作台、审计日志和退出登录，右上持续显示演示模式和固定账号权限。

### 4.2 任务区块

工作台使用“需要我处理/等待他人/最近处理”三个文字区块，不使用统计卡和效率排行。

### 4.3 任务行

显示任务类型、对象编号、脱敏来源、进入时间、当前状态和当前账号可执行操作，不显示完整正文、学生姓名或完整答卷。

### 4.4 筛选行

使用任务类型、状态和时间的轻量文字筛选，不制作复杂筛选面板、标签墙或批量选择。

### 4.5 详情操作区

统一放在任务详情右侧，承载开始处理、填写理由、提交、冲突和只读状态。四类任务只替换字段和按钮，不重新设计整页。

### 4.6 审计事件行

显示时间、事件、对象编号、操作权限、结果和模式；右侧详情显示操作事实，不复制完整正文、完整答案或未授权身份。

## 5. 统一状态词典

| 状态 | 统一表达 |
| --- | --- |
| 未开始 | 尚未记录 / 开始记录 |
| 进行中 | 正在处理 / 正在检查 |
| 已保存 | 已记录 / 已发布 |
| 等待确认 | 内容正在等待进一步确认 |
| 未公开 | 这段内容没有公开 |
| 失败 | 暂时没有完成 |
| 无权限 | 当前账号无法查看这部分内容 |
| 冲突 | 这条记录的状态已经变化，当前页面已只读 |
| 删除完成 | 从原列表消失并更新状态 |
| AI 回退 | 当前使用固定规则说明 |

同一状态不再创造多个同义词。

## 6. 页面组合

| 页面 | 主要组件 |
| --- | --- |
| 今日 | 顶栏、引导区、连续列表行、操作行、底部导航 |
| 自测中心 | 顶栏、引导区、模块列表、底部导航 |
| 答题页 | 顶栏、进度线、选项行、底部操作区 |
| 结果页 | 顶栏、固定总结、图表区、折叠区、操作行 |
| 树洞公共页 | 顶栏、筛选行、内容行、底部导航 |
| 发帖页 | 顶栏、文本输入区、话题选择、主要按钮 |
| 我的 | 顶栏、连续列表行、底部导航 |
| 支持资源 | 顶栏、说明、资源列表行 |

## 7. 首轮不制作的组件

- 头像大卡；
- 个人资料卡；
- 数据统计卡；
- 风险等级标签；
- 健康指数；
- 雷达图；
- 横向标签墙；
- 多级弹窗；
- 复杂图表图例；
- 独立通知中心；
- 自定义主题系统；
- Lieflat Charts Skill 运行依赖。

## 8. 验收条件

- 同一类内容在不同页面的组件表达一致；
- 组件状态不依赖单一颜色；
- 弹层可以明确关闭并返回原位置；
- 主要操作热区不小于 44px；
- 360px、375px、393px 和字体放大时组件不溢出；
- Web 端 1280px 和 1440×900 下详情操作区稳定；
- 组件复用后仍能保留今日、评测、树洞和我的各自语气；
- 首轮没有因为视觉需要新增复杂组件。
