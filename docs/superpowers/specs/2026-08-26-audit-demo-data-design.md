## 2. 页面结构

W-05 使用“左侧日志列表／右侧事件详情”结构，延续后台纯色背景、文字层级和细分隔线。顶部提供：

- 时间范围；
- 事件类型；
- 操作结果；
- 演示/授权模式；
- 对象编号。

首轮固定演示账号只有 `心理健康中心工作人员 / 超级管理员`，因此不提供角色选择；事件仍保留“操作权限”字段，用于表达真实系统中动作所属的能力边界。

列表字段：

| 字段 | 内容 |
| --- | --- |
| 时间 | 事件发生时间 |
| 事件 | 登录、认领、审核、授权、跟进等 |
| 对象 | 合成或真实授权对象编号 |
| 操作权限 | 内容审核、安全支持、身份授权、跟进或系统维护 |
| 结果 | 成功、失败、冲突、拒绝等 |
| 模式 | 演示模式或授权模式 |

不支持按正文、姓名、学号、手机号或学生关键词搜索。

## 3. 事件详情

详情显示：

- 操作者；
- 账号及权限；
- 对象编号；
- 事件类型；
- 操作动作；
- 理由或依据；
- 读取或改变的字段范围；
- 时间；
- 演示/授权模式；
- 操作结果；
- 模型与提示词版本（仅 AI 事件，不含原始输入输出）。

详情不复制：

- 完整树洞正文；
- 完整自测答案或总分；
- 未授权身份；
- 安全确认完整内容；
- AI 原始输入、输出、推理或置信度；
- 与当前事件无关的学生资料。

日志不可编辑、删除、覆盖、导出或重新执行。空状态为“暂时没有符合条件的记录”。无权限状态为“当前账号无法查看这部分审计记录”。

## 4. 必须记录的事件

### 4.1 会话与权限

- 登录、退出、会话过期；
- 权限失败；
- 演示模式进入；
- 低于桌面宽度的页面访问不记为敏感事件。

### 4.2 工作任务

- 任务认领、释放、提交；
- 他人认领和状态版本冲突；
- 保存或提交失败。

### 4.3 内容审核

- 公开；
- 保护展示；
- 暂不公开及其内部理由；
- 转安全复核；
- 自动检查失败进入人工确认；
- 用户撤回或删除内容。

### 4.4 安全支持

- 受限安全任务创建；
- 支持资源已经展示；
- 支持事实确认、转交、跟进和结束；
- 不记录完整安全内容或普通自测结果。

“我现在可以保证安全”不创建后台安全任务，也不单独生成安全事件；“我不太确定”和“我现在无法保证安全”只在演示环境或真实授权模式下记录最小必要事件。

### 4.5 身份授权

- 身份访问申请、批准、拒绝；
- 授权字段范围与有效期；
- 授权后实际展开受限字段；
- 到期和撤回。

批准本身与实际查看分开记录；没有展开字段时不虚构“已查看身份”。

### 4.6 AI

- 自测辅助说明成功或回退；
- 树洞辅助初筛成功或回退；
- 模型标识、解析后的版本、提示词版本、任务类型、结果和失败类别。

不记录模型原始请求、原始响应、学生完整文本或内部推理。

### 4.7 不记录的普通行为

- 普通筛选；
- 页面跳转；
- 一般任务列表浏览；
- 未展开敏感字段的普通详情查看；
- 今日页换短句等学生端普通交互。

## 5. 演示数据隔离

演示模式从 W-01 固定账号入口开始，并在 W-01 至 W-05 持续显示。固定账号为：

```text
心理健康中心工作人员 / 超级管理员
```

演示账号、帖子、回应、答卷、身份、安全任务、工作任务和审计均使用合成数据与独立命名空间。技术层至少使用独立 CloudBase 环境 ID；命名空间标识作为第二层保护，不能只依赖页面上的“演示模式”。

- 演示环境不能查询真实数据；
- 真实授权环境不能混入演示对象；
- 演示身份不代表真实学生；
- 演示审计不代表真实学校处理记录；
- 页面不得把“模拟跟进”写成“已联系学生”或“学校已介入”。

## 6. 首轮演示案例

| 领域 | 覆盖状态 |
| --- | --- |
| 内容审核 | 公开、保护展示、等待确认、暂不公开、自动检查失败、转安全复核 |
| 安全支持 | 待确认、支持已提供、跟进中、已结束 |
| 身份授权 | 申请中、已批准、已拒绝、已过期、已撤回、实际查看 |
| 工作任务 | 未认领、已认领、他人处理中、状态冲突、提交失败 |
| 学生端结果 | 普通、较高分数、AI 回退、安全支持 |
| 树洞 | 正常、保护、等待、未公开、安全优先、已删除 |
| 权限与会话 | 无权限、会话过期、低于 1280px |

案例必须通过正常页面操作改变状态，不提供任意字段编辑器直接改写结果。

## 7. 重置演示数据

W-05 末尾提供 `重置演示数据`。只有固定演示账号可以看到；真实授权环境不显示该操作。

确认层：

```text
演示数据将恢复到初始案例状态。
此操作不会影响真实数据。

取消
确认重置
```

重置后：

- 演示任务和案例回到固定初始状态；
- 演示身份授权全部失效；
- 上一次演示的未提交备注和临时敏感输入清除；
- 演示审计重新生成固定基线，并追加本次重置结果；
- 真实环境和真实数据不发生读写。

重置请求必须绑定演示环境与命名空间，二次确认后执行。失败时显示“演示数据暂时没有完成重置，请重新尝试”，不得显示部分成功为全部成功。

## 8. AI 回退

AI 不可用时：

- 自测显示“AI 辅助解读暂时不可用，当前使用固定规则说明”；
- 树洞内容保持不公开并进入人工确认；
- W-03 显示“自动检查未完成，请进行人工处理”；
- W-05 记录任务类型、模型/提示词版本和回退类别，不显示供应商错误、完整文本或模型置信度。

AI 失败不能阻断固定结果、支持资源、人工审核、演示重置或审计查看。

## 9. 验收条件

- W-05 全程只读，日志不能编辑、删除、导出或重新执行；
- 固定演示账号下不出现角色选择或切换；
- 日志与详情不包含完整正文、完整答案、未授权身份或 AI 原始内容；
- 实际展开 P3 字段与批准授权分开记审计；
- 普通筛选、跳转和一般浏览不进入日志；
- 演示模式在全部后台页面持续可见；
- 演示数据与真实数据环境级隔离；
- 重置只影响演示命名空间；
- AI 回退后固定规则与人工流程继续可用；
- 1280px 与 1440×900 下列表和详情稳定，低于 1280px 不显示受保护内容。
