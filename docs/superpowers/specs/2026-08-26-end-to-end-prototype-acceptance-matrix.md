## 2. 原型目标

端到端原型用于验证以下问题：

1. 学生能否从首次进入走完主要自助观察路径；
2. 普通观察、较高分数和安全支持是否被清楚区分；
3. 树洞是否保持匿名、克制和非资讯流体验；
4. 学生端、公共树洞和后台 Web 是否遵守各自的最小可见范围；
5. 删除、撤回、等待、过期、无权限和并发冲突是否有明确去向；
6. 暖雾纸白、静谧青和留白方向在真实移动端尺寸下是否可读；
7. 后台是否支持处理任务，而不是变成健康数据大屏。

原型使用合成账号、合成内容和演示数据。不得在原型中使用真实学生数据，也不得把演示安全支持任务描述为真实学校干预。

## 3. 端到端路径

### 3.1 新用户首次使用

路径：

基础同意 → 身份核验 → 今日 → 每日心情 → 自测中心。

需要验证：

- 基础同意说明是否简短、可理解；
- 身份核验是否说明用途和状态，而不是制造监控感；
- 今日页是否能自然引导每日心情；
- 自测入口是否说明“自我观察”而非诊断；
- 底部导航是否始终为今日、自测、树洞、我的；
- 返回路径和首次使用状态是否不会丢失。

### 3.2 回访用户与树洞

路径：

今日 → 树洞 → 社区审核同意 → 发帖 → 等待确认 → 我的树洞内容。

需要验证：

- 公共树洞不是新闻资讯流或卡片墙；
- 发帖前的社区规则和匿名说明足够明确；
- 提交后不会承诺审核时长；
- 等待确认不会进入公共流；
- 作者能在我的树洞内容中看到中性状态；
- 作者撤回后能看到清楚的结果；
- 公共内容、作者状态和后台审核状态相互对应但不互相泄露。

### 3.3 支持优先路径

路径：

PHQ-9 安全确认或树洞安全优先 → 支持资源 → 返回路径。

需要验证：

- 支持资源先于普通操作出现；
- 必要时不显示 AI 辅助解读；
- 不显示风险等级、模型置信度或历史轨迹；
- 紧急资源易发现，但页面不采用报警式铺满红色；
- 返回路径不会把用户强行带回答题或公共树洞；
- 不自动联系学校，也不自动公开到树洞。

### 3.4 记录回顾与数据管理

路径：

自测中心 → 近期记录/全部记录 → 结果回顾 → 我的 → 数据删除或账户删除确认。

需要验证：

- 无记录、部分记录和三项回顾就绪状态不同；
- 三项回顾不会被误读为综合健康指数；
- 历史记录按记录时间和模块区分，不制造排名；
- 删除前说明影响范围，删除后有明确状态；
- 账户删除确认不是轻触即执行；
- 我的页面保持工具感和私密感，不变成数据看板。

### 3.5 后台 Web 工作路径

路径：

固定账号进入 → 工作台 → 任务详情 → 认领 → 处理 → 提交 → 审计回溯。

需要验证：

- 真实环境与演示环境入口清楚分离；
- 当前账号及权限始终可见；
- 工作台只显示当前任务所需的最小事实；
- 内容审核、风险复核、身份授权和跟进工作互不越权；
- 任务被他人认领或已被其他处理流程改变时当前页面变为只读；
- 审计日志可回溯但不复制完整正文、完整答卷和未授权身份；
- 低于 1280px 时提示使用电脑浏览器，不压缩为移动端单列。

## 4. 学生端状态覆盖矩阵

| 模块 | 必须覆盖的状态 | 重点检查 |
| --- | --- | --- |
| 今日 | 首次进入、今日未记录、今日已记录、返回来源保留 | 是否安静、有下一步但不强迫 |
| 每日心情 | 未记录、已记录、重复查看、保存后返回 | 是否避免情绪标签化和颜色误导 |
| 自测中心 | 无记录、部分记录、三项回顾就绪、全部记录 | 是否不像综合健康看板 |
| PHQ-9/GAD-7 | 答题中、退出确认、普通结果、较高分数、AI 失败 | 是否固定计分、非诊断、无风险图表 |
| 安全流程 | 安全确认、支持优先、支持资源、返回 | 是否支持优先且不泄露内部判断 |
| 睡眠观察 | 未开始、部分记录、第 8 题跳过、完成、历史 | 是否明确是自定义观察，不冒充医学量表 |
| 结果页 | 首屏、回答构成折叠、回答指纹、历史、资源、再次记录 | 是否保持静默阅读式连续性 |
| 树洞公共页 | 空状态、正常公开、保护展示、回复 | 是否不像资讯流和热度榜 |
| 树洞发布 | 社区审核同意、编辑中、提交中、等待确认、撤回 | 是否不承诺时效、不自动公开 |
| 我的树洞内容 | 空列表、多状态列表、详情、删除后 | 是否只展示作者自己的状态 |
| 我的 | 身份核验状态、数据入口、账户删除确认 | 是否不显示后台申请和角色信息 |

## 5. 后台 Web 状态覆盖矩阵

| 模块 | 必须覆盖的状态 | 重点检查 |
| --- | --- | --- |
| 登录与会话 | 固定账号、演示模式、会话过期、退出 | 是否明确当前模式和账号权限，且不出现角色选择或切换 |
| 待办 | 需要我处理、等待他人、最近处理、空状态 | 是否不显示风险排行和处理倒计时 |
| 内容审核 | 未认领、已认领、自动检查失败、需人工确认、已提交、并发冲突 | 是否只显示脱敏文本和必要上下文 |
| 安全支持 | 待复核、已确认、需升级、跟进中、已结束、无权限 | 是否不显示完整答卷和其他模块 |
| 身份授权 | 申请中、批准、拒绝、短时可见、到期、撤回 | 是否最少字段、短时显示、可审计 |
| 跟进记录 | 待记录、编辑中、提交、状态变化、已结案 | 是否只记录事实，不替代安全判断 |
| 审计日志 | 登录、敏感访问、决定、权限失败、冲突、会话过期、演示重置 | 是否只读且不泄露原文和身份 |

## 6. 设备与版式覆盖

### 6.1 学生端

- 360px 宽度；
- 375×812；
- 393×852；
- 系统字体放大状态；
- 长标题、长正文、长按钮文案；
- 无数据、加载、失败和空白状态；
- 底部导航与系统安全区域；
- 键盘出现时的输入页面。

检查内容：

- 左右留白不会挤压主要操作；
- 留白不会让页面显得空洞或造成误以为内容缺失；
- 图表、正文和按钮不横向溢出；
- 主要热区不小于 44px；
- 状态不只依赖颜色；
- 支持资源和安全入口在小屏仍然容易找到。

### 6.2 后台 Web

- 1440×900 推荐工作尺寸；
- 1280px 最小可操作宽度；
- 低于 1280px 的提示状态；
- 长正文、长理由、长审计事件；
- 无任务、多人处理和权限不足状态；
- 浏览器窗口高度不足时的滚动行为。

检查内容：

- 左侧导航、顶部账号与模式栏和主工作区关系稳定；
- 队列和详情不会同时显示不必要的身份信息；
- 认领、提交和只读状态足够明显；
- 表格、筛选和详情不会变成数据大屏；
- 关键操作不依靠颜色或图标单独表达。

## 7. 验收矩阵

### 7.1 隐私与权限

- 未提交答题和未提交树洞不会出现在后台；
- 普通心情、普通 PHQ-9/GAD-7 和睡眠结果不会出现在后台；
- 内容审核员不能看到真实身份和完整自测；
- 安全支持能力只能看到已进入受限任务的最小安全事实；
- 身份字段只在受限申请批准后短时出现；
- 公共树洞不能显示等待确认、未公开或安全优先内容；
- 演示数据不能与真实数据交叉读取。

### 7.2 状态与安全

- 普通高分不显示为诊断、危险等级或红黄绿图表；
- PHQ-9 第 9 题非零但未完成安全确认时，不生成后台任务；选择“我现在可以保证安全”也不生成任务；只有“不太确定”或“无法保证安全”可在演示/真实授权模式下生成最小安全支持任务；
- 支持优先页面不显示不必要的 AI 内容；
- AI 失败时使用固定规则模板；
- 删除、撤回、过期、无权限和并发冲突都有对应文案；
- 安全资源比普通操作容易发现，但不使用持续闪烁或报警式动效。

### 7.3 视觉与信息架构

- 页面主体背景为纯色，不使用渐变、纹理、噪点、发光或阴影堆叠；
- 不使用卡片墙、新闻式信息流、健康指数、雷达图或风险图表；
- 树洞保持匿名轻社区气质；
- 自测结果保持静默阅读式连续性；
- 我的页面不变成统计看板；
- 图表只服务于分数定位、回答指纹、历史轨迹、睡眠定性观察和记录节奏；
- 颜色不是唯一信息通道；
- 主色和留白在不同屏幕上保持可读和可操作。

### 7.4 任务完成

- 新用户可以完成基础同意、核验并到达今日；
- 用户可以完成每日心情并回到今日；
- 用户可以开始、退出、完成和回顾自测；
- 用户可以从安全支持页面找到下一步和返回路径；
- 用户可以发帖、查看等待状态并在我的内容中找到它；
- 审核员可以从待办进入任务、认领、提交决定；
- 安全支持和身份授权能力不能通过普通内容任务路径越权；
- 关键操作均能在审计中找到对应事实。

## 8. 问题分级

### 阻断问题

包括身份泄露、跨能力越权、未提交数据外泄、错误医疗结论、错误安全处置暗示、演示数据进入真实范围、无法找到紧急支持资源等。必须修复后才能继续实现验收。

### 主要问题

包括关键路径中断、状态文案互相矛盾、页面在 360px 溢出、长文案不可读、删除或撤回没有去向、后台任务无法确认当前状态等。应在进入实现前关闭。

### 次要问题

包括间距微调、字号层级、图标一致性、非关键动效和局部视觉偏差。可以记录后集中处理，但不能改变已确认的权限和状态边界。

## 9. 原型交付物

原型阶段至少应形成：

1. 学生端四条端到端路径；
2. 后台 Web 五类工作路径；
3. 学生端和后台状态覆盖清单；
4. 360px、375px、393px 和字体放大截图；
5. 1440×900、1280px 和低于最小宽度提示截图；
6. 合成数据与演示账号说明；
7. 问题清单、分级、修正记录和最终验收结论；
8. 未通过项对产品决策、权限矩阵和状态机的影响说明。
