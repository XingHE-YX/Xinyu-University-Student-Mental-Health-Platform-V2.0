## 2. 设计目标

首次打开时让学生快速理解三件事：

1. 这里可以记录最近的感受；
2. 记录和树洞的隐私边界不同；
3. 这是自我观察工具，不是诊断系统。

今日页要让用户自然地开始一次轻量记录，而不是面对一个数据仪表盘。

## 3. 首次使用流程

### 3.1 基础同意

标题：

先从今天开始

说明：

心语帮助你记录最近的感受，做一些自我观察，也可以在树洞里匿名说说话。这里的内容用于自我了解，不替代专业诊断。

四行简要说明：

- 每日记录默认只属于你自己；
- 树洞使用匿名身份；
- 自测结果用于观察，不代表诊断；
- 你可以管理或删除自己的记录。

交互：

- 勾选：我已阅读并了解以上说明；
- 次级入口：查看完整说明；
- 主按钮：继续。

未勾选时主按钮不可提交，但不使用红色错误提示，只在按钮下方显示“请先确认你已了解以上说明”。

### 3.2 身份核验

标题：

先确认这是你的记录

说明：

身份核验只用于保存你的记录、区分账户和处理数据管理请求。它不会显示在公共树洞中，也不会作为树洞署名。

状态：

| 状态 | 页面表达 | 操作 |
| --- | --- | --- |
| 未开始 | 说明核验用途 | 开始核验 |
| 核验中 | 正在确认记录归属，请稍候。 | 暂不提供重复提交 |
| 失败 | 暂时没有完成核验，请重新尝试。 | 重新核验 |
| 完成 | 已确认这是你的记录。 | 进入心语 |

不显示复杂进度条、倒计时、后台审核、风险标签或身份详情。

## 4. 今日页

### 4.1 固定结构

页面从上到下为：

1. `今日`、日期和按时段变化的问候；
2. 一条随机短句、出处和 `换一句`；
3. “此时此刻”的每日心情；
4. “最近的自我观察”三条连续列表；
5. 树洞轻量入口；
6. 支持资源入口；
7. 底部导航。

四个底部导航固定为今日、自测、树洞、我的。

### 4.2 今日未记录

页面显示“还没有记录此刻”和整行操作 `记录此刻 >`。点击后打开固定底部浮层，使用愉快、平静、疲惫、焦虑、低落、烦躁六个单选项；初始次级操作为 `稍后再说`。保存失败时显示“暂时没有记下这次选择／重新试试 >”，不得显示为已记录。

### 4.3 今日已记录

页面显示“今天的心情：{心情}／已记录”。保存确认浮层只提供 `再看一眼`，关闭后回到今日；首版当天不提供修改入口。每日心情不影响短句、自测、树洞或后台，不显示情绪分数、连续天数、状态评级、好坏颜色或鼓励打卡。

### 4.4 自测入口

“最近的自我观察”固定使用情绪状态、焦虑状态、睡眠与恢复三条无外框列表。每行只显示最近记录日期或“尚未记录”，已完成进入对应结果，未完成进入模块开始页；区块标题右侧使用 `自测 >`。PHQ-9、GAD-7 和睡眠始终分别显示，不生成综合健康状态。

### 4.5 最近观察

若记录属于安全支持状态，该行只显示“这次记录需要先单独查看 >”，点击进入支持优先页，不在今日页展开分数、回答构成、风险判断或安全原因。

## 5. 视觉与版式

- 页面主体使用纯色背景；
- 360px/375px 左右留白 20px，393px 及以上 24px；
- 使用日期、标题、文字区块和 1px 分隔线组织内容；
- 不使用卡片墙、插画、空心图表或阴影堆叠；
- 今日页首屏应能看到记录心情和去自测；
- 主按钮高度 48px，主要触控区域不小于 44px；
- 状态不只依赖颜色；
- 今日页不使用安全砖红色作为普通提示；
- 短句从 `docs/v2/V2_DAILY_QUOTE_LIBRARY.md` 的已启用条目中抽取；现代作品候选在版权和正式译文核验前保持禁用。

## 6. 跳转和返回

首次使用流程 → 基础同意 → 身份核验 → 今日。

今日 → 页面内记录心情 → 今日已记录状态。

今日 → 自测 → 从自测返回时保留今日页滚动位置。

今日 → 树洞或我的 → 返回时回到对应主页面。

嵌套页面隐藏底部导航，使用带文字的返回入口；重复点击今日不强制回到顶部。

## 7. 验收条件

- 首次使用不依赖轮播或长篇阅读才能理解；
- 身份核验用途清楚，但不制造监控感；
- 今日页不是数据看板；
- 用户能在首屏找到记录心情和去自测；
- 已记录和未记录状态差异清楚；
- 身份字段、后台状态和安全判断不出现在今日页；
- 360px、375px、393px 和字体放大时无横向溢出；
- 返回后来源和滚动位置保持合理；
- 不使用颜色作为唯一状态通道。
