# 本地说明书演示环境

本入口仅在 `127.0.0.1` 启动服务，使用合成身份、内存业务仓储及后台预置演示任务。
不会连接真实学校、CloudBase 数据库或 DeepSeek。停止进程后，本地新增记录不保留。

在项目根目录启动两个终端：

```bash
backend/.venv/bin/python deploy/local/backend_demo.py
node deploy/local/admin_preview.mjs
```

后端地址为 `http://127.0.0.1:9000`，后台为 `http://127.0.0.1:5173`。
后台测试密码为 `LocalManual-2026!`，只用于该本地演示入口。

微信开发者工具打开 `miniprogram/`。`config/local-preview.ts` 仅在开发者工具中
启用回环地址；正式微信客户端继续使用已配置的 HTTPS 服务地址或明确的未配置状态。
模拟身份核验示例：姓名“演示同学”，学号“DEMO20260916”。这些值不对应真实学生。

界面截图使用基础库 3.16.1；3.17.2 下普通页面可显示，但本机官方自动化接口的
页面数据命令曾超时。使用微信官方自动化接口时应选用已验证的基础库。
